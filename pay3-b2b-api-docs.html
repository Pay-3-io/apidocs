Pay3 External API (1.0.0)

Download OpenAPI specification:

A system that allows external corporations (Partners) to use Pay3’s card issuance, KYC, and payment infrastructure while maintaining their own UI.

Card issued Webhook

Delivered to the client's registered webhook_url when a card is issued.

Headers

  • X-Pay3-Signature: hex(HMAC_SHA256(webhook_secret, rawBody)) — verify with your shared secret.
  • X-Pay3-Event: event type (e.g. card.issued).
  • X-Pay3-Delivery: delivery ID (use for idempotent handling of retries).

Retries: non-2xx responses are retried with exponential backoff (30s, 60s, 120s … up to 1h). Respond 2xx quickly and dedupe on X-Pay3-Delivery.

Request Body schema: application/json
id
string

Delivery ID (matches X-Pay3-Delivery)

type
string
created_at
string <date-time>
data
object

Event-specific payload (the issued card)
